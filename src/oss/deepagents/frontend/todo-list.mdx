不是每一次 agent interaction 都是 chat。有时 agent 正在执行一个 multi-step plan，而展示进度的最佳方式是一个实时更新的 **todo list**。deep agent todo list pattern 会直接从 agent state 读取 `todos` array，并在 agent 执行计划时用当前 status 渲染每个 item。它是一个建立在你用于 chat 的同一个 `useStream` hook 之上的 progress dashboard。它说明了 agent state 可以驱动任何 UI，而不只是 message bubbles。

## 工作原理 {#how-it-works}

在 LangGraph agent 中，state 不限于 messages。你可以定义 **custom state keys** 来保存任意数据。在这个例子里，就是一个 `todos` array。当 agent 执行计划时，它会将每个 todo 的 status 从 `"pending"` 更新到 `"in_progress"`，再更新到 `"completed"`。`useStream` hook 会通过 `stream.values` 暴露这些 custom state values，你的 UI 会响应式地渲染它们。

流程如下：

1. 用户提交 request
2. Agent 创建 plan，并在 state 中填充 `todos`
3. Agent 开始执行，每个 todo 会从 `pending` 转为 `in_progress`，再转为 `completed`
4. 随着 agent 推进，`stream.values.todos` 会实时更新
5. 你的 UI 用当前 statuses 重新渲染 todo list

## 设置 useStream {#setting-up-usestream}

不需要特殊配置。让 `useStream` 指向你的 agent，并从 `stream.values` 读取 `todos` 即可。

:::python

定义一个与你的 agent state schema 匹配的 TypeScript interface，并将它作为 type parameter 传给 `useStream`，从而类型安全地访问 state values，包括 `todos` 这样的 custom state keys。在下面的示例中，请将 `typeof myAgent` 替换为你的 interface 名称：

```ts
import type { BaseMessage } from "@langchain/core/messages";

interface TodoItem {
  title: string;
  status: "pending" | "in_progress" | "completed";
  description?: string;
}

interface AgentState {
  messages: BaseMessage[];
  todos: TodoItem[];
}
```

:::

:::js

导入你的 agent，并将 `typeof myAgent` 作为 type parameter 传给 `useStream`，从而类型安全地访问 state values：

```ts
import type { myAgent } from "./agent";
```

:::

## Todo 接口 {#the-todo-interface}

array 中的每个 todo 都有一个简单结构：

```ts
interface Todo {
  status: "pending" | "in_progress" | "completed";
  content: string;
}
```

| 属性 | 说明 |
| --- | --- |
| `status` | 这个 task 的当前状态。选项：`pending`（尚未开始）、`in_progress`（agent 正在处理）、`completed`（已完成） |
| `content` | 对 task 内容的人类可读描述 |

agent 在创建 plan 时填充这个 array，然后在执行每个步骤时更新单个 items。

## 构建 TodoList 组件 {#building-the-todolist-component}

todo list 会用 status icon、color coding 和反映当前 state 的 visual styling 渲染每个 item：

```tsx
function TodoList({ todos }: { todos: Todo[] }) {
  const completed = todos.filter((t) => t.status === "completed").length;
  const percentage = todos.length
    ? Math.round((completed / todos.length) * 100)
    : 0;

  return (
    <div className="rounded-lg border bg-white p-4 shadow-sm">
      <div className="mb-4 flex items-center justify-between">
        <h2 className="text-lg font-semibold">Agent Progress</h2>
        <span className="text-sm text-gray-500">
          {completed}/{todos.length} tasks
        </span>
      </div>

      <ProgressBar percentage={percentage} />

      <ul className="mt-4 space-y-2">
        {todos.map((todo, i) => (
          <TodoItem key={i} todo={todo} />
        ))}
      </ul>
    </div>
  );
}
```

visual progress bar 能让用户一眼看到整体完成情况：

## 单个 todo 项 {#individual-todo-items}

每个 item 都会有一个 status icon、按颜色区分的 text，以及 completed tasks 的 strikethrough styling：

```tsx
function TodoItem({ todo }: { todo: Todo }) {
  const config = {
    pending: {
      icon: "○",
      textClass: "text-gray-600",
      bgClass: "bg-gray-50",
      iconClass: "text-gray-400",
    },
    in_progress: {
      icon: "●",
      textClass: "text-amber-800",
      bgClass: "bg-amber-50 border-amber-200",
      iconClass: "text-amber-500 animate-pulse",
    },
    completed: {
      icon: "✓",
      textClass: "text-green-800 line-through",
      bgClass: "bg-green-50 border-green-200",
      iconClass: "text-green-500",
    },
  };

  const style = config[todo.status];

  return (
    <li
      className={`flex items-start gap-3 rounded-md border px-3 py-2 ${style.bgClass}`}
    >
      <span className={`mt-0.5 text-lg leading-none ${style.iconClass}`}>
        {style.icon}
      </span>
      <span className={`text-sm ${style.textClass}`}>{todo.content}</span>
    </li>
  );
}
```

`in_progress` icon 使用 `animate-pulse`，用来吸引用户注意当前 active task。

## 计算进度 {#calculating-progress}

直接从 todos array 派生 progress metrics：

```ts
const todos = stream.values?.todos ?? [];

const completed = todos.filter((t) => t.status === "completed").length;
const inProgress = todos.filter((t) => t.status === "in_progress").length;
const pending = todos.filter((t) => t.status === "pending").length;
const percentage = todos.length
  ? Math.round((completed / todos.length) * 100)
  : 0;
```

随着 agent 修改 state，这些 values 会响应式更新，让 progress bar 和 counters 保持同步。

## 与 chat 消息结合 {#combining-with-chat-messages}

todo list 可以和常规 chat interface 一起工作。一个实用 layout 会把 todo list 显示为持久 sidebar 或 header panel，并在下方显示 chat messages：

```tsx
function TodoAgentLayout() {
  const stream = useStream<typeof myAgent>({
    apiUrl: AGENT_URL,
    assistantId: "deep_agent_todo_list",
  });

  const todos = stream.values?.todos ?? [];

  return (
    <div className="flex h-screen flex-col">
      {todos.length > 0 && (
        <div className="border-b bg-gray-50 p-4">
          <TodoList todos={todos} />
        </div>
      )}

      <main className="flex-1 overflow-y-auto p-6">
        <div className="mx-auto max-w-2xl space-y-4">
          {stream.messages.map((msg) => (
            <Message key={msg.id} message={msg} />
          ))}
        </div>
      </main>

      <ChatInput
        onSubmit={(text) =>
          stream.submit({ messages: [{ type: "human", content: text }] })
        }
        isLoading={stream.isLoading}
      />
    </div>
  );
}
```

<Tip>
只有当 `todos.length > 0` 时才显示 todo list。在 agent 创建 plan 之前，没有任何内容需要显示。显示空 component 会浪费空间。
</Tip>

## Todos 之外的自定义状态 {#custom-state-beyond-todos}

这个 pattern 展示了一个强大的原则：`stream.values` 可以暴露 agent 定义的 **任何 custom state**，不只是 messages。`todos` array 只是一个例子。你可以用同样的方法实现：

- **Progress metrics**：`stream.values.progress`，包含数值化 completion data
- **Generated artifacts**：`stream.values.document`，包含 agent 正在构建的 structured document
- **Decision logs**：`stream.values.decisions`，跟踪 agent 做出的每个选择
- **Resource lists**：`stream.values.sources`，包含 agent 找到的 links 和 references

```ts
// Any custom state key your agent defines is accessible
const document = stream.values?.document;
const sources = stream.values?.sources ?? [];
const confidence = stream.values?.confidence_score;
```

<Info>
Custom state keys 在你的 LangGraph graph 的 state schema 中定义。`useStream` hook 会自动将它们包含在 `stream.values` 中，不需要额外的 client-side configuration。
</Info>

## 动画化过渡 {#animating-transitions}

Todo status transitions 会实时发生，smooth animations 会让这些变化显得精致，而不是突兀：

```tsx
function TodoItem({ todo }: { todo: Todo }) {
  return (
    <li
      className={`
        flex items-start gap-3 rounded-md border px-3 py-2
        transition-all duration-300 ease-in-out
        ${getStatusStyles(todo.status)}
      `}
    >
      <span
        className={`
          mt-0.5 text-lg leading-none transition-colors duration-300
          ${getIconStyles(todo.status)}
        `}
      >
        {getStatusIcon(todo.status)}
      </span>
      <span
        className={`
          text-sm transition-all duration-300
          ${todo.status === "completed" ? "line-through opacity-60" : ""}
        `}
      >
        {todo.content}
      </span>
    </li>
  );
}
```

`transition-all duration-300` classes 确保 color changes、strikethrough 和 opacity shifts 都能平滑动画。

## 使用场景 {#use-cases}

todo list pattern 适合任何 agent 执行 structured plan 的场景：

- **Project planning**：agent 将 project 拆分为 tasks，并按顺序处理
- **Research workflows**：每个 research question 都成为一个 todo，agent 会调查并完成它
- **Data processing**：ingestion、validation、transformation 和 export 等步骤各自成为 todo
- **Onboarding flows**：agent 逐步完成 setup steps，并在配置 services 时逐项勾选
- **Report generation**：报告的各个 sections 变成 todos：gather data、analyze trends、write summary、format output

## 处理空状态和加载状态 {#handling-empty-and-loading-states}

在 agent 尚未创建 plan 前处理 initial state：

```tsx
function TodoList({ todos, isLoading }: { todos: Todo[]; isLoading: boolean }) {
  if (todos.length === 0 && !isLoading) {
    return null;
  }

  if (todos.length === 0 && isLoading) {
    return (
      <div className="rounded-lg border bg-white p-4 shadow-sm">
        <div className="flex items-center gap-2 text-sm text-gray-500">
          <span className="animate-spin">◌</span>
          Agent is creating a plan...
        </div>
      </div>
    );
  }

  return (
    <div className="rounded-lg border bg-white p-4 shadow-sm">
      {/* ... full todo list rendering */}
    </div>
  );
}
```

## 最佳实践 {#best-practices}

- **突出显示 todo list**。它是 plan-based agents 的主要 progress indicator。不要把它埋到首屏以下。
- **为 status transitions 添加动画**。平滑 transitions 会让 agent 显得更 responsive。对 background color、text decoration 和 opacity 使用 CSS transitions。
- **只高亮一个 `in_progress` item**。Agents 通常一次处理一个 task。如果多个 items 都显示为 `in_progress`，UI 会变得嘈杂。可以考虑只让第一个 pulsing。
- **折叠或弱化 completed items**。随着列表变长，completed items 的相关性会降低。降低它们的 visual weight，让用户关注仍在发生的内容。
- **显示 progress percentage**。像“67% complete”这样的单个数字非常容易理解。
- **保持 todo list 同步**。因为 `stream.values` 会响应式更新，todo list 会自动保持最新。不要添加手动 polling 或 refresh logic。
