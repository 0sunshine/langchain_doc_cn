将自定义 synchronous [subagents](/oss/javascript/deepagents/subagents) 定义为 markdown files，这样 Deep Agents Code 就可以把 specialized tasks 委派给它们。

<Note>
    Deep Agents Code 目前不支持 async subagents。
</Note>

每个 subagent 都位于自己的 folder 中，并包含一个 `AGENTS.md` 文件：

```text
.deepagents/agents/{subagent-name}/AGENTS.md   # Project-level
~/.deepagents/{agent}/agents/{subagent-name}/AGENTS.md  # User-level
```

同名情况下，project subagents 会覆盖 user subagents（参见 [precedence rules](/oss/javascript/deepagents/code/data-locations#subagents)）。

frontmatter 必须包含 `name` 和 `description`（与 [`SubAgent` dictionary spec](/oss/javascript/deepagents/subagents#subagent-dictionary-based) 相同）。markdown body 会成为 subagent 的 `system_prompt`。除了基础 spec 之外，`AGENTS.md` files 还支持可选的 `model` frontmatter field，用于为该 subagent 覆盖 main agent 的 model。它使用 `provider:model-name` 格式（例如 `anthropic:claude-opus-4-7`、`openai:gpt-5.5`）。省略该字段则继承 main agent 的 model。

<Note>
    其他 `SubAgent` fields（`tools`、`middleware`、`interrupt_on`、`skills`）目前无法通过 `AGENTS.md` frontmatter 配置。以这种方式定义的 custom subagents 会继承 main agent 的 tools。若需要完整控制，请直接使用 SDK。
</Note>

## File format

Subagent `AGENTS.md` files 使用 YAML frontmatter，后面跟 markdown body：

```markdown
---
name: researcher
description: Research topics on the web before writing content
model: anthropic:claude-haiku-4-5-20251001
---

You are a research assistant with access to web search.

## Your Process
1. Search for relevant information
2. Summarize findings clearly
```

## Example: cost-efficient subagents

为简单 delegation tasks 使用更便宜、更快的 model，同时让 main agent 继续使用更强的 model：

```markdown
---
name: general-purpose
description: General-purpose agent for research and multi-step tasks
model: anthropic:claude-haiku-4-5-20251001
---

You are a general-purpose assistant. Complete the task efficiently and return a concise summary.
```

这会覆盖 built-in general-purpose subagent，把所有 delegated tasks 路由到更便宜的 model。更多信息请参阅 [Override the general-purpose subagent](/oss/javascript/deepagents/subagents#override-the-general-purpose-subagent)。
