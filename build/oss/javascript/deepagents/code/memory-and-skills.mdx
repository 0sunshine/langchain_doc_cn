自定义任何 agent 主要有两种方式：

- **[Memory](#memory)**：跨 sessions 持久化的 `AGENTS.md` files 和 auto-saved memories。使用 memory 保存通用 coding style、preferences 和 learned conventions。

- **[Skills](#skills)**：Global 和 project-specific context、conventions、guidelines 或 instructions。使用 skills 保存只在执行特定 tasks 时适用的 context。

使用 `/remember` 可以显式提示 agent 根据当前 conversation 更新 memory 和 skills。

<Tip>
    正在用 SDK 构建 custom agent？请参阅 [Memory](/oss/javascript/deepagents/memory) 了解 programmatic memory backends。
</Tip>

## Memory

### 自动 memory {#automatic-memory}

随着你使用 agent，它会按照 memory-first protocol，把信息作为 markdown files 自动存储在 `~/.deepagents/<agent_name>/memories/`：

1. **Research**：开始 tasks 前搜索 memory 中的相关 context
2. **Response**：执行过程中不确定时检查 memory
3. **Learning**：自动保存新信息，供 future sessions 使用

agent 会按 topic 组织 memories，并使用描述性 filenames：

```text
~/.deepagents/backend-dev/memories/
|-- api-conventions.md
|-- database-schema.md
`-- deployment-process.md
```

当你教给 agent conventions：

```bash
dcode --agent backend-dev
> Our API uses snake_case and includes created_at/updated_at timestamps
```

它会在 future sessions 中记住：

```bash
> Create a /users endpoint
# Applies conventions without prompting
```

### AGENTS.md 文件 {#agents-md-files}

[`AGENTS.md` files](https://agents.md/) 提供 session start 时始终加载的 persistent context：

- **Global**：`~/.deepagents/<agent_name>/AGENTS.md` - 每个 session 都会加载。
- **Project**：任何 git project root 中的 `.deepagents/AGENTS.md` - 从该 project 内运行 Deep Agents Code 时加载。

两个文件都会在 startup 时追加到 system prompt。

### Memory 工作原理 {#how-memory-works}

当回答 project-specific questions，或者当你引用过去的 work 或 patterns 时，agent 也可能读取它的 memory files。

当你提供关于 agent 应如何表现的信息、对它工作的 feedback，或要求它记住某些内容时，agent 会更新 `AGENTS.md`。
如果它从你的 interactions 中识别出 patterns 或 preferences，也会更新自己的 memory。

如果要在额外 memory files 中添加更结构化的 project knowledge，请把它们放进 `.deepagents/`，并在 `AGENTS.md` file 中引用。
你必须在 `AGENTS.md` file 中引用额外 files，agent 才会知道它们存在。
这些额外 files 不会在 startup 时读取，但 agent 可以在需要时 reference 和 update 它们。

### 何时使用 global 与 project AGENTS.md {#when-to-use-global-vs-project-agents-md}

使用 global `AGENTS.md`（`~/.deepagents/agent/AGENTS.md`）保存：

- 你的 personality、style 和 universal coding preferences
- 通用 tone 和 communication style
- 通用 coding preferences（formatting、type hints 等）
- 适用于所有地方的 tool usage patterns
- 不随 project 改变的 workflows 和 methodologies

使用 project `AGENTS.md`（project root 中的 `.deepagents/AGENTS.md`）保存：

- Project-specific context 和 conventions
- Project architecture 和 design patterns
- 该 codebase 特有的 coding conventions
- Testing strategies 和 deployment processes
- Team guidelines 和 project structure

## Skills

Skills 是 reusable agent capabilities，可提供 specialized workflows 和 domain knowledge。
你可以使用 [skills](/oss/javascript/deepagents/skills) 为 deep agent 提供新的 capabilities 和 expertise。
Deep agent skills 遵循 [Agent Skills standard](https://agentskills.io/)。
一旦添加了 skills，deep agent 会在你使用 agent 并提供额外信息时自动使用并更新它们。

### 添加 skills {#add-skills}

<Steps>
    <Step title="创建 skill">

        ```bash
        # User skill (stored in ~/.deepagents/<agent_name>/skills/)
        dcode skills create test-skill

        # Project skill (stored in .deepagents/skills/)
        dcode skills create test-skill --project
        ```

        这会生成：

        ```plaintext
        skills/
        `-- test-skill
            `-- SKILL.md
        ```

    </Step>
    <Step title="编辑 SKILL.md">
        打开生成的 `SKILL.md`，编辑该 file 以加入你的 instructions。
    </Step>
    <Step title="添加可选 resources">
        可选地向 `test-skill` folder 添加 additional scripts 或其他 resources。更多信息请参阅 [Examples](/oss/javascript/deepagents/skills#example)。
    </Step>
</Steps>

你也可以把 existing skills 直接复制到 agent 的 folder：

```bash
mkdir -p ~/.deepagents/<agent_name>/skills
cp -r examples/skills/web-research ~/.deepagents/<agent_name>/skills/
```

### 安装 community skills {#install-community-skills}

你可以使用 Vercel 的 [Skills CLI](https://github.com/vercel-labs/skills) 等 tools 在环境中安装 community [Agent Skills](https://agentskills.io/)，并让 deep agents 可以使用它们：

```bash
# Install a skill globally
npx skills add vercel-labs/agent-skills --skill web-design-guidelines -a deepagents -g -y

# List installed skills
npx skills ls -a deepagents -g
```

Global installs（`-g`）会把 skills symlink 到 `~/.deepagents/agent/skills/`，也就是默认 agent 的 user-level skills directory。Project-level installs（省略 `-g`）会把 skills 放在当前 directory 下的 `.deepagents/skills/`，让在该 project 中运行的任何 agent 都能使用它们，而不受 agent name 影响。

<Note>
    Global installs 只指向默认的 `agent` directory。如果你使用 custom-named agent，请使用 project-level installs，或手动把 skill symlink 到 `~/.deepagents/{your-agent}/skills/`。
</Note>

### Skill 发现 {#skill-discovery}

startup 时，Deep Agents Code 会从 Deep Agents 和 shared alias directories 中发现 skills：

```text
~/.deepagents/<agent_name>/skills/
~/.agents/skills/
.deepagents/skills/
.agents/skills/
~/.claude/skills/          (experimental)
.claude/skills/            (experimental)
```

当存在 duplicate skill names 时，later-precedence directories 会覆盖 earlier ones（参见 [App data](/oss/javascript/deepagents/code/data-locations#skills)）。

对于 project-specific skills，project root folder 必须包含 `.git` folder。
当你从 project folder 内任何位置启动 Deep Agents Code 时，它会通过查找包含它的 `.git` folder 来找到 project root folder。

对于每个 skill，Deep Agents Code 会读取 `SKILL.md` file frontmatter 中的 name 和 description。
随着你使用 Deep Agents Code，如果某个 task 匹配 skill 的 description，agent 会读取 skill file 并遵循其中的 instructions。

你也可以使用 `/skill:<name> [args]` 直接调用 skill。Skill discovery 会在 startup 时运行，也会在 `/reload` 时再次运行。

### 从 command line 调用 skill {#invoke-a-skill-from-the-command-line}

使用 `--skill` 可以在 launch 时调用 skill，而不必在交互中输入 slash command：

```bash
# Open the TUI and immediately run a skill
dcode --skill code-review

# Pass a request to the skill with -m
dcode --skill code-review -m 'review the auth module'

# Pipe content into a skill
cat diff.txt | dcode --skill code-review

# Pipe content and add a request
cat diff.txt | dcode --skill code-review -m 'focus on security'
```

`--skill` 也适用于 non-interactive mode：

```bash
# Run a skill headlessly
dcode --skill code-review -n 'review this patch'

# Quiet mode (only agent output on stdout)
dcode --skill code-review -n 'review this patch' -q
```

<Note>
    `--skill` 搭配 `--quiet` 或 `--no-stream` 时需要 `-n`（non-interactive mode）。
</Note>

### 列出 skills {#list-skills}

```bash
# List all user skills
dcode skills list

# List project skills
dcode skills list --project

# Get detailed info about a specific skill
dcode skills info test-skill
dcode skills info test-skill --project
```
