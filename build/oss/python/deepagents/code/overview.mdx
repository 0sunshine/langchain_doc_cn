Deep Agents Code（`dcode`）是一个基于 [Deep Agents SDK](/oss/python/deepagents/quickstart) 构建的 open source coding agent。
它可与任何支持 tool calling 的 LLM 配合使用，并允许你在 inputs 之间切换 LLMs。
它会保留 conversations 中学到的 persistent memory，跨 sessions 维护 context，使用可自定义的 skills，并通过 approval controls 执行 code。

## 快速开始 {#quickstart}

<Steps>

    <Step title="安装并启动" icon="terminal">
        OpenAI、Anthropic 和 Google 默认已安装。其他 providers（Ollama、Groq、xAI 等）可作为 optional extras 使用。详情请参阅 [Providers](/oss/python/deepagents/code/providers)。

        <CodeGroup>
            ```bash Script
            curl -LsSf https://langch.in/dcode | bash
            ```

            ```bash Optional extras
            # Example: install with Fireworks and Nvidia providers
            DEEPAGENTS_EXTRAS="fireworks,nvidia" curl -LsSf https://langch.in/dcode | bash

            # OpenAI, Anthropic, and Gemini are included by default
            # View all extras:
            # https://docs.langchain.com/oss/python/deepagents/code/providers
            ```

            ```bash uv
            # Example: install with Fireworks and Nvidia providers
            uv tool install 'deepagents-code[fireworks,nvidia]'

            # OpenAI, Anthropic, and Gemini are included by default
            # View all extras:
            # https://docs.langchain.com/oss/python/deepagents/code/providers
            ```
        </CodeGroup>

        ```bash
        dcode
        ```
        ![Deep Agents Code](/oss/images/deepagents/deepagents-cli.png)

    </Step>

    <Step title="添加 provider 凭证" icon="key">
        Deep Agents Code 可与任何支持 tool calling 的 LLM 配合使用。使用 `/auth` command 为你选择的 providers 设置 API key。完整流程和存储细节请参阅 [Provider credentials](/oss/python/deepagents/code/configuration#provider-credentials)。

        其他 providers 和 headless runs 请参阅 [Providers](/oss/python/deepagents/code/providers)。

        <Note>
            Web search 使用 [Tavily](https://tavily.com)，且 **不会** 通过 `/auth` 配置。如果 startup 时看到 "Web search disabled - `TAVILY_API_KEY` is not set"，请把 `TAVILY_API_KEY=tvly-...` 添加到 `~/.deepagents/.env`，然后运行 `/reload`（或重启）。参见 [Enable web search with Tavily](/oss/python/deepagents/code/configuration#enable-web-search-with-tavily)。
        </Note>
    </Step>

    <Step title="给 agent 一个任务" icon="message">
        ```txt
        Create a Python script that prints "Hello, World!"
        ```

        agent 会解释 query，并在修改 files 前通过 diffs 提出 changes 供你 approval。必要时，它可以运行 shell commands 来测试 code、检查 documentation，或搜索 web 获取最新信息。
    </Step>

    <Step title="启用 tracing（可选）" icon="chart-dots">
        要在 LangSmith 中记录 agent operations、tool calls 和 decisions，请把以下内容添加到 `~/.deepagents/.env`，或在 shell 中 export variables：

        ```bash title="~/.deepagents/.env"
        LANGSMITH_TRACING=true
        LANGSMITH_API_KEY=lsv2_...
        LANGSMITH_PROJECT=optional-project-name  # Specify a project name or default to "deepagents-code"
        ```

        更多详情和用法请参阅 [Trace with LangSmith](#trace-with-langsmith)。
    </Step>
</Steps>

<Note>
    Deep Agents Code 未正式支持 Windows。Windows users 可以尝试在 [Windows Subsystem for Linux (WSL)](https://learn.microsoft.com/en-us/windows/wsl/install) 下运行。
</Note>

## 能力 {#capabilities}

Deep Agents Code 内置以下 capabilities：

* <Icon icon="file" size={16} /> **File operations** - 使用 tools read、write、edit files，让 agents 可以管理并修改 code 和 documentation。
* <Icon icon="terminal" size={16} /> **Shell execution** - 执行 commands 来运行 tests、build projects、管理 dependencies，并与 version control 交互。
* <Icon icon="cloud" size={16} /> **[Remote sandboxes](/oss/python/deepagents/code/remote-sandboxes)** - 在 LangSmith、Daytona、Modal、Runloop 或 AgentCore 中运行 agent tools，而不是在本机运行。链接页面涵盖 provider installation、credentials、sandbox flags（`--sandbox`、`--sandbox-id`、`--sandbox-setup`）和 setup scripts。
* <Icon icon="search" size={16} /> **Web search** - 搜索 web 获取最新 information 和 documentation。需要在 [`TAVILY_API_KEY`](/oss/python/deepagents/code/configuration#enable-web-search-with-tavily) 中设置 Tavily API key。
* <Icon icon="globe" size={16} /> **HTTP requests** - 向 APIs 和 external services 发起 HTTP requests，用于 data fetching 和 integration tasks。
* <Icon icon="list-check" size={16} /> **Task planning and tracking** - 将复杂 tasks 分解成明确 steps 并跟踪 progress。
* <Icon icon="users" size={16} /> **[Subagents](/oss/python/deepagents/code/subagents)** - 使用 `task` tool 委派工作。在 Deep Agents Code 中，可将 custom subagents 定义为 `AGENTS.md` files；链接页面涵盖 paths、frontmatter 和 examples。
* <Icon icon="brain" size={16} /> **[Memory storage and retrieval](/oss/python/deepagents/code/memory-and-skills#memory)** - 跨 sessions 存储和检索 information，让 agents 记住 project conventions 和 learned patterns。
* <Icon icon="arrows-minimize" size={16} /> **Context compaction & offloading** - 总结较早 conversation messages，并把 originals offload 到 storage，在 long sessions 中释放 context window space。
* <Icon icon="user" size={16} /> **Human-in-the-loop** - 对 sensitive tool operations 要求 human approval。
* <Icon icon="puzzle" size={16} /> **[Skills](/oss/python/deepagents/code/memory-and-skills#skills)** - 用 custom expertise 和 instructions 扩展 agent capabilities。
* <Icon icon="plug" size={16} /> **[MCP tools](/oss/python/deepagents/code/mcp-tools)** - 从 [Model Context Protocol](https://modelcontextprotocol.io/) servers 加载 external tools。
* <Icon icon="chart-dots" size={16} /> **[Tracing](/oss/python/deepagents/code/overview#trace-with-langsmith)** - 在 LangSmith 中 trace agent operations，用于 observability 和 debugging。

<Accordion title="完整内置工具列表" id="full-list-of-built-in-tools">
    ## 内置 tools

    agent 随附以下 built-in tools，无需配置即可使用：

    | Tool | Description | Human-in-the-Loop |
    |------|-------------|-------------------|
    | `ls` | 列出 files 和 directories | - |
    | `read_file` | 读取 file 内容；部分 models 支持 multimodal content | - |
    | `write_file` | 创建或覆盖 file | Required<sup>1</sup> |
    | `edit_file` | 对 existing files 做 targeted edits | Required<sup>1</sup> |
    | `glob` | 查找匹配 pattern 的 files | - |
    | `grep` | 跨 files 搜索 text patterns | - |
    | `execute` | 在本地或 remote sandbox 中执行 shell commands | Required<sup>1</sup> |
    | `web_search` | 使用 Tavily 搜索 web（需要 `TAVILY_API_KEY`，参见 [Enable web search](/oss/python/deepagents/code/configuration#enable-web-search-with-tavily)） | Required<sup>1</sup> |
    | `fetch_url` | 获取并将 web pages 转换为 markdown | Required<sup>1</sup> |
    | `task` | 把工作委派给 subagents 并行执行 | Required<sup>1</sup> |
    | `ask_user` | 向 user 提出 free-form 或 multiple-choice questions | - |
    | `compact_conversation` | 总结较早 messages，把 originals offload 到 backend storage，并用 summary 替换 context 中的内容 | Mixed<sup>2</sup> |
    | `write_todos` | 为复杂 work 创建并管理 task lists | - |

    <sup>1</sup>：Potentially destructive operations 在执行前需要 user approval。要绕过 human approval，可以 toggle auto-approve（shift+tab），或使用以下 option 启动：

    ```bash
    dcode -y
    # or
    dcode --auto-approve
    ```

    <Note>
        以 non-interactive 方式运行 Deep Agents Code（通过 `-n` 或 piped stdin）时，即使带 `-y`/`--auto-approve`，shell execution 默认也是 disabled。使用 `-S`/`--shell-allow-list` allowlist specific commands（例如 `-S "pytest,git,make"`），使用 `recommended` 获取 safe defaults，或使用 `all` 允许任何 command。也支持 `DEEPAGENTS_CODE_SHELL_ALLOW_LIST` environment variable。更多详情请参阅 [Non-interactive mode and piping](#non-interactive-mode-and-piping)。
    </Note>

    <sup>2</sup>：当 token usage 超过 model-aware threshold 时，Deep Agents Code 会自动在后台 offload conversation。Offloading 会通过 LLM 总结较早 messages，并把 originals eject 到 storage（`/conversation_history/{thread_id}.md`），再用 summary 替换 context 中的内容。必要时，agent 仍可从 offloaded file 中检索 full history。`compact_conversation` tool 允许 agent（或你）按需触发 offloading。作为 tool 调用时，它默认需要 user approval。
</Accordion>

## 命令参考 {#command-reference}

```bash
# Use a specific agent configuration
dcode --agent mybot

# Use a specific model (provider:model format or auto-detect)
dcode --model anthropic:claude-opus-4-7
dcode --model gpt-5.5

# Auto-approve tool usage (skip human-in-the-loop prompts)
dcode -y

# list directory contents, then summarize directory as first prompt - the command runs first, then the prompt is submitted
# the prompt does NOT have access to the command output
dcode --startup-cmd "ls -la" -m "Summarize what's in this directory"

# Non-interactive with startup command: show git status before the task runs
# the task does NOT have access to the command output
dcode --startup-cmd "git diff --stat" -n "Review these changes"
```

## 配置 {#configuration}

完整 reference（包括 `config.toml` schema、provider parameters、profile overrides 和 hook configuration）请参阅 [Configuration](/oss/python/deepagents/code/configuration)。

Deep Agents Code 会把所有 configuration 存在 `~/.deepagents/` 下。在该 directory 内，每个 agent 都有自己的 subdirectory（default：`agent`）：

| 路径 | 用途 |
|------|---------|
| `~/.deepagents/config.toml` | Model 和 agent defaults、provider settings、constructor params、profile overrides、themes、update settings、MCP trust store |
| `~/.deepagents/.env` | Global API keys 和 secrets。参见 [configuration](/oss/python/deepagents/code/configuration#environment-variables) |
| `~/.deepagents/hooks.json` | Lifecycle event hooks（session start/end、task complete 等） |
| `~/.deepagents/<agent_name>/` | Per-agent memory、skills 和 conversation threads |
| `.deepagents/` (project root) | Project-specific memory 和 skills，在 git repo 内运行时加载 |

```bash
# List all configured agents
dcode agents list
```

## 非交互模式和管道 {#non-interactive-mode-and-piping}

使用 `-n` 运行单个 task，而不启动 interactive UI：

```bash
dcode -n "Write a Python script that prints hello world"
```

你也可以通过 stdin pipe 输入。input 被 pipe 时，Deep Agents Code 会自动以 non-interactive 方式运行：

```bash
echo "Explain this code" | dcode
cat error.log | dcode -n "What's causing this error?"
git diff | dcode -n "Review these changes"
git diff | dcode --skill code-review -n 'summarize changes'
```

当你将 piped input 与 `-n` 或 `-m` 组合时，piped content 会先出现，然后是你传给 flag 的 text。

<Note>
    最大 piped input size 是 10 MiB。
</Note>

non-interactive mode 中 shell execution 默认 disabled。使用 `-S`/`--shell-allow-list` 启用特定 commands（例如 `-S "pytest,git,make"`），使用 `recommended` 获取 safe defaults，或使用 `all` 允许任意 command。

<AccordionGroup>
    <Accordion title="使用 `--max-turns` 限制 turn 数" id="cap-turn-count-with-max-turns" icon="gauge">
        CI/CD pipelines 中 long-running 或 misbehaving agents 可能无限循环。`--max-turns N` 为 operators 提供 hard upper bound，而不必触碰 SDK internals：

        ```bash
        dcode -n "fix the failing tests" --max-turns 10
        ```

        `N` 必须是 positive integer，并覆盖内部 safety default。budget exceeded 时以 code 124 退出（匹配 GNU `timeout`），因此 CI 可以区分 budget hit 和 generic failure。需要 `-n` 或 piped stdin；否则以 code 2 退出。

        如果想使用 time-based limit 而不是（或同时使用）turn-count limit，请参阅 [Cap wall-clock time with `--timeout`](#non-interactive-mode-and-piping)。
    </Accordion>

    <Accordion title="使用 `--timeout` 限制实际耗时" id="cap-wall-clock-time-with-timeout" icon="clock">
        `--timeout SECONDS` 为 non-interactive run 强制 hard wall-clock limit。它用 time-based budget 补充 `--max-turns`（turn count），哪个 limit 先命中就取消 agent。

        ```bash
        # Fail fast in CI if the task takes more than 2 minutes
        dcode -n "run the test suite and summarise failures" --timeout 120

        # Combine with --max-turns - whichever limit is hit first stops the agent
        dcode -n "refactor auth module" --timeout 300 --max-turns 20
        ```

        到期时 agent 会被 cancelled，process 以 code 124 退出，与 `--max-turns` 使用同一 code，因此 CI 可以统一处理两种 budget hits。需要 `-n` 或 piped stdin；否则以 code 2 退出。
    </Accordion>

    <Accordion title="干净输出和缓冲" id="clean-output-and-buffering" icon="buffer">
        使用 `-q` 生成适合 pipe 到其他 commands 的 clean output，并使用 `--no-stream` 在写入 stdout 前 buffer 完整 response（而不是 streaming）：

        ```bash
        dcode -n "Generate a .gitignore for Python" -q > .gitignore
        dcode -n "List dependencies" -q --no-stream | sort
        ```

        non-interactive mode 中，agent 会被指示做合理假设并自主推进，而不是提出 clarifying questions。它也会偏好 non-interactive command variants（例如 `npm init -y`、`apt-get install -y`）。
    </Accordion>

    <Accordion title="Shell 执行示例" id="shell-execution-examples" icon="shield-check">
        ```bash
        # Allow specific commands (validated against the list)
        dcode -n "Run the tests and fix failures" -S "pytest,git,make"

        # Use the curated safe-command list
        dcode -n "Build the project" -S recommended

        # Allow any shell command
        dcode -n "Fix the build" -S all
        ```
    </Accordion>
</AccordionGroup>

<Warning>
    **Use with caution.**

    `-S all`（或 `--shell-allow-list all`）允许 agent 在没有 human confirmation 的情况下执行 arbitrary shell commands。
</Warning>

## 使用 LangSmith trace {#trace-with-langsmith}

启用 [LangSmith](https://smith.langchain.com?utm_source=docs&utm_medium=cta&utm_campaign=langsmith-signup&utm_content=oss-deepagents-code-overview) tracing，可以在 LangSmith project 中查看 agent operations、tool calls 和 decisions。

把 tracing keys 添加到 `~/.deepagents/.env`，这样每个 session 都会启用 tracing，而不需要每个 shell 单独 export：

```bash title="~/.deepagents/.env"
LANGSMITH_TRACING=true
LANGSMITH_API_KEY=lsv2_...
LANGSMITH_PROJECT=optional-project-name  # Specify a project name or default to "deepagents-code"
```

如果要为特定 project override，请把相同 keys 添加到 project directory 中的 `.env`。完整 loading order 请参阅 [environment variables](/oss/python/deepagents/code/configuration#environment-variables)。

如果你更喜欢，也可以把这些设置为 shell environment variables。Shell exports 总是优先于 `.env` values，因此很适合 temporary overrides 或 testing：

```bash
export LANGSMITH_TRACING=false
```

<Accordion title="将 agent traces 与 app traces 分离" id="separate-agent-traces-from-app-traces">
    以编程方式从 LangChain application 调用 Deep Agents Code 时（例如在 [non-interactive mode](#non-interactive-mode-and-piping) 中作为 subprocess），你的 app 和 Deep Agents Code 都会生成 LangSmith traces。默认情况下，它们都会进入同一个 project。

    要把 Deep Agents Code traces 发送到 dedicated project，请设置 `DEEPAGENTS_CODE_LANGSMITH_PROJECT`：

    ```bash title="~/.deepagents/.env"
    DEEPAGENTS_CODE_LANGSMITH_PROJECT=my-deep-agent-execution
    ```

    然后为 parent application 的 traces 配置 `LANGSMITH_PROJECT`：

    ```bash title="~/.deepagents/.env"
    LANGSMITH_PROJECT=my-app-traces
    ```

    这样可以保持 app-level observability 清爽，同时仍在 separate project 中捕获 agent 的 internal execution。

    你也可以使用 [`DEEPAGENTS_CODE_` prefix](/oss/python/deepagents/code/configuration#deepagents_code_-prefix) 将 LangSmith credentials scoped 到 Deep Agents Code（例如 `DEEPAGENTS_CODE_LANGSMITH_API_KEY`）。
</Accordion>

配置完成后，Deep Agents Code 会显示带 LangSmith project link 的 status line。在支持的 terminals 中，点击 link 即可直接打开。也可以使用 `/trace` 打印 URL 并在 browser 中打开。

```sh
LangSmith tracing: 'my-project'
```
