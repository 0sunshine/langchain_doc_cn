本指南会带你创建第一个具备 planning、file system tools 和 subagent 能力的 deep agent。你将构建一个可以进行研究并撰写报告的 research agent。

<Tip>
    **正在使用 AI coding assistant？**

    - 安装 [LangChain Docs MCP server](/use-these-docs)，让你的 agent 能访问最新的 LangChain 文档和示例。
    - 安装 [LangChain Skills](https://github.com/langchain-ai/langchain-skills)，提升 agent 处理 LangChain 生态任务的表现。
</Tip>

## 前置条件

开始之前，请确保你已经从某个 model provider（例如 Gemini、Anthropic、OpenAI）获取了 API key。

<Note>
    Deep Agents 需要支持 [tool calling](/oss/langchain/models#tool-calling) 的 model。如何配置 model，请参阅 [customization](/oss/deepagents/customization#model)。
</Note>

## Step 1：安装依赖

:::python
<CodeGroup>
    ```bash pip
    pip install deepagents tavily-python
    ```

    ```bash uv
    uv init

    ```
</CodeGroup>
:::

:::js
<CodeGroup>
    ```bash npm
    npm install deepagents langchain @langchain/core @langchain/tavily
    ```

    ```bash yarn
    yarn add deepagents langchain @langchain/core @langchain/tavily
    ```

    ```bash pnpm
    pnpm add deepagents langchain @langchain/core @langchain/tavily
    ```
</CodeGroup>
:::

<Note>
    本指南使用 [Tavily](https://tavily.com/) 作为示例 search provider，但你可以替换为任何 search API（例如 DuckDuckGo、SerpAPI、Brave Search）。
</Note>

## 它是如何工作的？

你的 deep agent 会自动：

1. **规划方法**：使用内置 [`write_todos`](/oss/deepagents/harness#task-planning) tool 分解 research task。
1. **开展研究**：调用 `internet_search` tool 收集信息。
1. **管理 context**：使用 file system tools（[`write_file`](/oss/deepagents/harness#virtual-filesystem-access)、[`read_file`](/oss/deepagents/harness#virtual-filesystem-access)）将大型 search results 转存出去。
1. **按需生成 subagents**：将复杂 subtasks 委派给专用 subagents。
1. **综合报告**：将发现整理成连贯的 response。

## Streaming

Deep Agents 内置 [streaming](/oss/langchain/event-streaming)，可基于 LangGraph 从 agent execution 中获取实时更新。
这让你可以逐步观察输出，并 review 和 debug agent 与 subagent 的工作，例如 tool calls、tool results 和 LLM responses。

## 下一步

现在你已经构建了第一个 deep agent：

- **Customize your agent**：了解 [customization options](/oss/deepagents/customization)，包括 custom system prompts、tools 和 subagents。
- **添加 long-term memory**：在 conversations 之间启用 [persistent memory](/oss/deepagents/memory)。
- **部署到生产环境**：使用 [Managed Deep Agents](/langsmith/deploy-managed-deep-agent) 在 LangSmith 中创建、运行和运维 deep agents。
